HERMES MOBILE · APP DESIGN v1

One companion app for your Hermes agents

Chat-first. Approvals are always one tap away. The Hermes features that make sense on a phone each have a home in one of five tabs. Desktop-only views are listed in the coverage notes.

Chat
Home. Talk to the active Bot.
  • Streaming replies and live tool activity
  • Model, reasoning and fallback picker
  • Sessions, search and session history
  • Checkpoints and rollback
  • Review changes (git diffs, worktrees)
  • Voice mode, wake word, read-aloud
  • Artifacts and preview rail
  • Turn-failed recovery
Bots
Each Hermes profile is a Bot.
  • Roster with sections, search and active filter
  • New Bot with clone, model pin, SOUL.md
  • Bot profile: avatar, skills, toolsets, voice
  • Group chats of 2 to 6 Bots with @mentions
  • Bot-to-bot messages and "needs you" flags
Inbox
Everything waiting for you.
  • Command approvals with a visible timer
  • Agent questions (clarify)
  • Cron and routine output
  • Failed runs with retry
  • Group chat "needs you" items
  • Pairing requests from messaging users
Tasks
Work that runs on its own.
  • Cron jobs: list, editor, delivery target
  • Kanban board across profiles and lanes
  • Task drawer: deps, comments, attachments
  • Goals, recurring loops, heartbeats
  • Batch processing progress
Control
Everything else, grouped.
  • Gateways and gateway status
  • Memory, skills, toolsets, MCP
  • Channels, pairing, webhooks
  • Analytics, logs, config
  • Security, approval policy, API keys
  • Settings, updates, backup, doctor
Decisions for you
  1. Connection. Hermes has no phone-pairing flow today. The design connects by gateway URL plus sign-in (Nous Portal, username and password on a trusted network or VPN, or Hermes Cloud). A QR pairing like OpenClaw's needs a new pairing endpoint on the Hermes side. Keep it out of v1, or add it?
  2. Theme. v1 is dark only. Hermes ships 8 desktop themes. Add a light theme, or map the app to Hermes themes later?
  3. Device capabilities. OpenClaw's phone nodes (camera, location, photos, screen) are not in Hermes. Not designed. Add them as a later phase?
  4. Canvas. Hermes has Artifacts, not a canvas. The design uses an Artifacts gallery with a preview rail.
  5. Inbox as a tab. Approvals time out after 300 seconds, so they get a tab of their own rather than a menu item.
